# P2-1 — The list-shaped config path passes the array straight to the …

## Finding / 问题

- EN: The list-shaped config path passes the array straight to the constructor: `["pattern" => ["/^[a-z]+$/"]]` throws `TypeError: PatternValidator::__construct(): Argument #1 ($pattern) must be of type string, array given` and `["minLength" => [5]]` likewise. Enum survives only because its first parameter is `string|array`. The same syntactic shape is therefore valid for one validator and fatal for another, and the behaviour is pinned by a test as intentional but never documented.
