# P2-2 — Map-form config silently discards unknown keys via …

## Finding / 问题

- EN: Map-form config silently discards unknown keys via `array_intersect_key`, so a typo weakens the rule instead of failing: `["minLength" => ["mn" => 5]]` passes "ab" (the key is dropped and minLength falls back to its default), and `["pattern" => ["patern" => "/^[a-z]+$/"]]` passes "123". The correct keys behave normally; the failure mode is "silently never fails".
- 中文: 映射形态配置用 array_intersect_key 静默丢弃未知键，因此拼错会让规则变弱而不是报错：["minLength" => ["mn" => 5]] 让 "ab" 通过（键被丢弃，minLength 回到默认值），["pattern" => ["patern" => "/^[a-z]+$/"]] 让 "123" 通过。写对键则正常；失败模式是「静默永不失败」。
- Where / 位置: `src/Validator.php:292-305`
- Verification / 验证: reproduced / 已实证
